# Telegram Bot для передачи показаний приборов учета

Бот для управления показаниями счетчиков (вода, электричество, газ) с использованием PostgreSQL и Telegram API.

## 📋 Требования

- Python 3.8+
- PostgreSQL 12+
- Telegram Bot Token

## 🚀 Установка

### 1. Установка зависимостей

```bash
pip install python-telegram-bot psycopg2-binary
```

### 2. Настройка базы данных

```bash
# Создайте базу данных
createdb meter_db

# Импортируйте схему
psql -U postgres -d meter_db -f schema.sql
```

### 3. Настройка переменных окружения

Создайте файл `.env` или установите переменные:

```bash
export TELEGRAM_BOT_TOKEN='your_bot_token_here'
export DB_NAME='meter_db'
export DB_USER='postgres'
export DB_PASSWORD='your_password'
export DB_HOST='localhost'
export DB_PORT='5432'
```

### 4. Запуск бота

```bash
python meter_reader_bot.py
```

## 📱 Использование

### Команды бота

- `/start` - Приветствие и начало работы
- `/cabinet` - Личный кабинет (адрес, приборы учета, последние показания)
- `/select_address` - Выбрать/сменить адрес
- `/help` - Справка
- `/cancel` - Отмена текущего действия

### Возможности

1. **Личный кабинет жителя**
   - Отображение текущего адреса
   - Список всех приборов учета
   - Последние показания по каждому счетчику
   - Дата и время последней передачи

2. **Передача показаний**
   - Отправка фото счетчика
   - Ручной ввод числового значения
   - Поддержка десятичных чисел (точка или запятая)

3. **Управление адресами**
   - Выбор из списка доступных адресов
   - Привязка нескольких адресов к пользователю
   - Переключение между адресами

## 🗄️ Структура базы данных

### Таблицы

- `addresses` - Адреса жилых помещений
- `meters` - Приборы учета (счетчики)
- `users` - Пользователи Telegram
- `user_addresses` - Привязка пользователей к адресам
- `readings` - История показаний

### Типы счетчиков

- `water_cold` - Холодное водоснабжение (ХВС)
- `water_hot` - Горячее водоснабжение (ГВС)
- `electricity` - Электричество
- `gas` - Газ

## 🔧 Настройка

### Добавление новых адресов

```sql
INSERT INTO addresses (street, building, apartment) 
VALUES ('ул. Новая', '25', '10');
```

### Добавление счетчиков

```sql
INSERT INTO meters (address_id, name, meter_type, serial_number) 
VALUES (1, 'ХВС Кухня', 'water_cold', 'SN12345678');
```

## 📝 Примечания

- Фотографии сохраняются в папку `photos/`
- OCR распознавание находится в разработке
- Все даты хранятся в часовом поясе сервера

## 🛠️ Разработка

Для добавления новых функций:

1. Обновите `schema.sql` при изменениях в БД
2. Добавьте новые обработчики в `meter_reader_bot.py`
3. Протестируйте изменения
