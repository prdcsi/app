# 🔐 Secure Messenger - Защищённый мессенджер

Современный веб-мессенджер со сквозным шифрованием для безопасного общения с друзьями.

## 🛡️ Технологии шифрования

Мессенджер использует передовые криптографические протоколы:

- **Сквозное шифрование (E2EE)** - сообщения шифруются на устройстве отправителя и дешифруются только на устройстве получателя
- **Протокол Диффи-Хеллмана (ECDH)** - безопасный обмен ключами между пользователями
- **AES-256-GCM** - современное симметричное шифрование сообщений
- **SHA-256** - хэширование для проверки целостности данных
- **Web Crypto API** - использование нативных браузерных криптографических функций

## 💡 Как это работает

1. **Генерация ключей**: При первом запуске генерируется пара криптографических ключей (публичный и приватный)
2. **Обмен ключами**: Пользователи обмениваются публичными ключами через защищённый канал
3. **Вычисление общего секрета**: По протоколу Диффи-Хеллмана вычисляется общий секретный ключ
4. **Шифрование сообщений**: Каждое сообщение шифруется алгоритмом AES-256-GCM перед отправкой
5. **Дешифрование**: Получатель расшифровывает сообщение используя общий секретный ключ

## 🔒 Безопасность

- Ключи никогда не передаются по сети
- Приватные ключи хранятся только в памяти устройства
- Сервер не имеет доступа к содержимому сообщений
- Каждое сообщение имеет уникальный вектор инициализации (IV)
- Реализована проверка целостности сообщений через хэширование

## 📝 Примечание

Это демонстрационная версия мессенджера. Для полноценного использования необходимо:

1. Настроить сервер для обмена сообщениями (WebSocket/Socket.io)
2. Реализовать хранение ключей в IndexedDB или localStorage
3. Добавить систему аутентификации пользователей
4. Интегрировать настоящую реализацию Web Crypto API
5. Добавить поддержку медиафайлов и голосовых сообщений
